# 앱이 읽는 원본 자료

`수원서베이_학습결과_정리본`에서 앱과 테스트에 필요한 파일만 골라 같은 폴더 구조로 복사한 것이다.
`scripts/make_source_data.py`가 만든다. 직접 고치지 않는다.

- `07_데이터/`: 2023~2025년 수원서베이의 집단별 응답 분포(개인 단위 자료는 없다), 문항표, 집단 정보, 평가용 프롬프트
- `03_예측/`: 학습한 어댑터 세 개가 연구실 GPU 서버에서 낸 예측. `adapter` 값의 서버 경로만 폴더 이름으로 줄였다
- `01_결과표/`: 칸 단위 오차. 앱이 계산한 값과 견주는 테스트에 쓴다
